Trayectorias y fractalidad en sistemas de partículas cercanos a una transición líquido-sólido

Programas de prueba generados para el estudio de la dimension fractal. En SRC se incluye un generador de trayectorias que se guardan en data\trayetcorias, por otro aldo se analizan estas trayectorias y se obtienen dimensiones fractales y se guardan estos datos en data_dimension.
